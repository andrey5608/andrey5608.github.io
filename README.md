# Portfolio

This repository contains the source code and build output for a personal portfolio site based on Gatsby and the @lekoarts/gatsby-theme-cara theme.

## Project Overview

- Framework: Gatsby (v2)
- Theme: @lekoarts/gatsby-theme-cara
- Content: MDX sections in src/@lekoarts/gatsby-theme-cara/sections/
- Output: Static site in public/ (generated by Gatsby)

## Getting Started

### Prerequisites

- Node.js (LTS recommended)
- npm or yarn

### Install Dependencies

npm install

or

yarn install

### Development

npm run develop

or

yarn develop

Open http://localhost:8000 in your browser.

### Production Build

npm run build

or

yarn build

The static site will be generated in the public/ directory.

### Serve Production Build Locally

npm run serve

or

yarn serve

## Deployment

This repo is configured to deploy to GitHub Pages using the gh-pages package.

npm run deploy

This command builds the site and publishes the public/ folder to the master branch.

## Configuration

Site metadata and plugins are configured in gatsby-config.js.
